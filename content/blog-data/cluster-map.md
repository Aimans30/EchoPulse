# Cluster map and topic bank

Read by the blog engine every run (BLOG-ENGINE.md section 3). Last revised 18
November 2026 by hand; the run cannot edit it, so always check a gap against
the live Sanity list before writing it.

A cluster is one selling page plus the posts that feed it. Every cluster
wants, in this order: one cost post (the pillar), one "X vs Y" or "compared by
price" post, one spec or template, one "how to choose". Posts in a cluster
link to each other.

"Live" lists topics that already exist: they are refreshed (section 8), never
written again. "Gaps to write" is where candidates come from. A cluster marked
full takes no new post.

Known traps:

- Statistics in these topics are mostly vendors quoting each other. Trace each
  one to its origin (section 4 step 6) or leave it out.
- Course-operations posts (completion rates, course length) draw impressions
  and no buyers. They are refreshed for links, never added to.
- Before 18 November 2026 several posts were published with a generic money
  link. A refresh sets `icp`, `service` and `moneyPage` properly.
